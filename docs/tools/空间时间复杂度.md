一、基本定义

1. 时间复杂度
   · 表示算法运行时间随输入规模（n）增长的变化趋势。
   · 关注点：操作次数（如循环、比较等），而非实际时间（秒）。
2. 空间复杂度
   · 表示算法运行过程中临时占用的内存空间随输入规模（n）增长的变化趋势。
   · 关注点：额外空间（如数组、变量等），不包括输入数据本身。

---

二、计算方法

1. 时间复杂度

步骤：

1. 找出算法中的基本操作（如单层循环中的语句）。
2. 计算基本操作的执行次数 T(n) 关于 n 的表达式。
3. 用大O表示法简化（保留最高阶项，忽略系数和低阶项）。

示例：

```python
for i in range(n):          # 执行n次
    print(i)                # 基本操作：O(1)
```

· 总操作次数：T(n) = n * O(1) = O(n)。

2. 空间复杂度

步骤：

1. 统计算法中额外分配的变量、数据结构（如数组、递归栈）。
2. 计算其空间占用与 n 的关系。
3. 用大O表示法简化。

示例：

```python
res = [0] * n               # 额外空间：O(n)
for i in range(n):
    res[i] = i
```

· 空间复杂度：O(n)（因数组 res 的大小与 n 成正比）。

---

三、常见复杂度分类

1. 时间复杂度

复杂度 名称 例子 解释
O(1) 常数时间 数组访问 arr[0] 操作次数与 n 无关
O(log n) 对数时间 二分查找 每次将问题规模减半
O(n) 线性时间 遍历数组 操作次数与 n 成正比
O(n log n) 线性对数 快速排序 分治算法典型复杂度
O(n²) 平方时间 双重循环（冒泡排序） 嵌套循环常见
O(2ⁿ) 指数时间 斐波那契递归（未优化） 避免使用，性能极差

2. 空间复杂度

复杂度 例子 解释
O(1) 原地反转链表 仅用固定数量的指针变量
O(n) 归并排序的临时数组 额外空间与输入规模成正比
O(log n) 快速排序的递归调用栈 递归深度为树高
O(n) 递归斐波那契（无记忆化） 递归栈深度达 n

四、如何快速判断？

时间复杂度的“看循环”法则

1. 单层循环：通常为 O(n)。
   ```python
   for i in range(n):  # O(n)
   ```
2. 嵌套循环：循环层数相乘。
   ```python
   for i in range(n):      # O(n)
       for j in range(n):  # O(n) → 总 O(n²)
   ```
3. 分治算法：通常含 O(log n)。
   ```python
   while n > 1:           # O(log n)（如二分查找）
       n = n // 2
   ```

空间复杂度的“看变量”法则

1. 固定变量：O(1)。
   ```python
   a, b = 1, 2  # 空间不变
   ```
2. 动态数据结构：O(n)。
   ```python
   res = [0] * n  # 数组大小随n增长
   ```
3. 递归调用：递归深度决定空间。
   ```python
   def f(n):      # 递归深度n → O(n)
       if n == 0: return
       f(n-1)
   ```

五、易混淆场景

1. 递归的时间复杂度

· 斐波那契递归：
  ```python
  def fib(n):
      if n <= 1: return n
      return fib(n-1) + fib(n-2)  # O(2ⁿ) 指数级！
  ```
  · 原因：存在大量重复计算（可优化为 O(n) 或 O(log n)）。

2. 原地操作的空间复杂度

· 反转数组：
  ```python
  def reverse(arr):
      left, right = 0, len(arr)-1  # O(1) 空间
      while left < right:
          arr[left], arr[right] = arr[right], arr[left]
          left += 1; right -= 1
  ```
  · 关键：未使用额外数据结构，仅用固定变量。

六、记忆口诀

1. 时间复杂度：
   · “单层循环 O(n)，嵌套乘起来，分治想对数，递归看树高。”
2. 空间复杂度：
   · “变量固定 O(1)，数组随 n 走，递归看栈深。”

七、实战练习

1. 计算以下代码的复杂度：
   ```python
   def example(arr):
       total = 0                     # O(1) 空间
       for num in arr:               # O(n) 时间
           total += num
       for i in range(len(arr)):     # O(n) 时间
           for j in range(len(arr)): # O(n) 时间
               print(i, j)
       return total
   ```
   · 答案：时间 O(n²)，空间 O(1)。

题目4：分治算法

```python
def func4(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = func4(arr[:mid])   # 递归处理左半
    right = func4(arr[mid:])  # 递归处理右半
    return merge(left, right) # merge函数假设为O(n)

def merge(a, b):
    # 合并两个有序数组，时间复杂度O(n)
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] < b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result
```

问题：func4 的时间复杂度和空间复杂度分别是多少？（这是归并排序的核心部分）

---

答案与解析

题目1：单层循环

· 时间复杂度：O(n)
  · 单层循环，循环次数与 n 成正比。
· 空间复杂度：O(1)
  · 只用了固定变量 count 和 i。

题目2：嵌套循环

· 时间复杂度：O(n²)
  · 双重循环，每次外层循环执行 n 次内层循环，总次数为 n * n。
· 空间复杂度：O(1)
  · 仅用固定变量 count、i、j。

题目3：递归调用（斐波那契）

· 时间复杂度：O(2ⁿ)
  · 递归树每层分裂为2个子问题，总节点数为 2ⁿ - 1（指数级）。
  · 优化方法：记忆化可降为 O(n)。
· 空间复杂度：O(n)
  · 递归深度为 n，栈空间最大占用 O(n)。

题目4：分治算法（归并排序）

· 时间复杂度：O(n log n)
  · 分治层数为 log n，每层合并操作总时间为 O(n)。
· 空间复杂度：O(n)
  · 递归栈空间 O(log n)，但合并时需要临时数组 O(n)，主导项为 O(n)。

题目5：动态数组扩容

· 时间复杂度：均摊 `O(n)`
  · 虽然单次 append 可能触发扩容（O(k) 时间，k 为当前大小），但均摊到 n 次操作后为 O(n)。
  · 详解：Python列表扩容策略为“超量分配”，扩容次数为 O(log n)，总操作次数为 n + n/2 + n/4 + ... ≈ 2n。
· 空间复杂度：O(n)
  · 最终列表大小为 n。

总结技巧

1. 时间复杂度：
   · 数循环次数，嵌套循环相乘，递归画树形图，分治想 log n。
2. 空间复杂度：
   · 看变量和数据结构，递归看栈深度，动态数组看最终大小。
